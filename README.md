**The Copper Ladle** — a diner-rescue cooking game drawn entirely in code. Cook Rosa has twelve days to repay a $4,390 loan or the bank takes her diner. Seat six kinds of customers, cook 26 recipes across five stations (chop, grill, fry, boil, bake), catch the golden PERFECT window before dishes burn, stack every dish layer by layer on the plate, and spend the night's earnings in a shop of eight working upgrades. Warm lamp-lit art, a sleeping cat, procedural music and sound — no image assets, no libraries, no network: every pixel is drawn by the game's own canvas code.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser. To hand the entry in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
